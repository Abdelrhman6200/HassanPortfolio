# Hassan Mohamed — Portfolio

Self-contained React/Vite portfolio export with bundled visual assets and all 15 portfolio case-study pages.

## Run locally

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm run build
```

Images are in `client/public/assets/`. The source PDFs are preserved in `reference/`.

## Push to GitHub

Create an empty GitHub repository, then run from this folder:

```bash
git init
git add .
git commit -m "Add Hassan Mohamed portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```
